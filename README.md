# Priority Outage Report Automation

Enterprise automation for generating standardized Priority Outage Reports using Microsoft Excel VBA.

---

## Overview

Priority Outage Reports were previously generated manually by extracting ticket data, identifying action items, formatting the report, and preparing it for operational review.

This project automates the complete workflow, reducing repetitive manual effort while improving reporting consistency and accuracy.

---

## Problem

The manual process involved:

- Importing exported ticket data
- Removing unnecessary columns
- Extracting action items from multiline fields
- Cleaning report data
- Sorting records
- Applying standardized formatting
- Preparing the final report

The process required approximately **1,800 minutes (30 hours)** of manual effort each month.

---

## Solution

The automation performs:

- Automated workbook import
- Data transformation
- Action item extraction
- Text normalization
- Report formatting
- Chronological sorting
- Standardized report generation

---

## Tech Stack

- Excel VBA
- Microsoft Excel
- Process Automation
