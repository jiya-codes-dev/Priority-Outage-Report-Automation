
## Getting Started

### Prerequisites

- Microsoft Excel with Macros enabled
- Exported incident report in `.xlsx` format

### Usage

1. Download or export the incident report.
2. Place the input file in the same directory as the automation workbook (or update the input file path in the VBA source if required). For eg in my automation I've said - Copy and paste the Attachment (Incidents Report in this case) in "C:\MPC\DB" folder.
3. Open `Priority-Outage-Report-Automation.xlsm`.
4. Enable macros when prompted.
5. Click **Generate Report** button.
6. The standardized Priority Outage Report will be generated automatically.
